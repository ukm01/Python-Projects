
# Retail Analytics Portfolio Project

## Goal
Build an industry-level analytics project using:
- VS Code
- Python/Pandas for data cleaning and ETL
- SQL for analysis
- Power BI for dashboarding

## Dataset
Synthetic Indian retail dataset:
- customers.csv: customer master data
- products.csv: product master data
- stores.csv: store master data
- orders.csv: 300,000 order rows
- returns.csv: returned orders
- schema.sql: SQL table creation script
- starter_queries.sql: first business queries

## Business Questions
1. What are monthly revenue, profit, and order trends?
2. Which categories and products generate the most revenue?
3. Which channels perform best: Online, Store, or App?
4. What is the return rate and refund impact?
5. Which customer segments are most valuable?
6. Which cities/states generate the most sales?
7. What are the best KPIs for a Power BI executive dashboard?

## Suggested Dashboard Pages
1. Executive Summary
2. Sales Trend Analysis
3. Product & Category Performance
4. Customer Segment Analysis
5. Returns & Refund Analysis
